# Touchline

A football management game with less detail than Football Manager but real depth. Fictional leagues, a deterministic match engine and an animated momentum view of the pitch. Desktop browser first; English and Swedish.

- Vision: [docs/vision.md](docs/vision.md)
- Architecture: [docs/architecture.md](docs/architecture.md)
- Contributing (humans and agents): [CLAUDE.md](CLAUDE.md)
