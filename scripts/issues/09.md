## Goal
Shared types for match input, state and events.

## Acceptance criteria
- [ ] `TeamMatchProfile` with phase ratings: build-up, progression, chance creation, finishing, pressing, defending, goalkeeping (0..1)
- [ ] `MatchInput` (home, away, tactics placeholders) and `MatchState` (time, period, possession, ball x/y, danger level, score)
- [ ] `MatchEvent` union: kickoff, progress, turnover, shot (with xG and outcome), goal, corner, foul, period change
- [ ] Builders for tests (`aTeamProfile()`, `aMatchInput()`)
- [ ] Types documented with short comments
