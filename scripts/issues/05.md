## Goal
Saving has one interface so storage can change (IndexedDB now, Tauri later) without touching game code.

## Acceptance criteria
- [ ] `SaveStore` interface: `list()`, `load(id)`, `save(id, data)`, `delete(id)`, all async
- [ ] In-memory implementation
- [ ] A reusable **contract test suite** that any `SaveStore` implementation must pass
- [ ] Save envelope type `{ schemaVersion, createdAt, game }` and a migration runner skeleton with tests
