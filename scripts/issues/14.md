## Goal
Lively, varied commentary generated from events, in both languages.

## Acceptance criteria
- [ ] Templates per event type with several variants per locale
- [ ] Uses a separate rng stream so commentary never changes the simulation
- [ ] Grammar helpers, starting with Swedish genitive (`Kvarnby` to `Kvarnbys`, names ending in s unchanged)
- [ ] Player names only on goals (as in the prototype)
- [ ] Periodic summaries (possession over the last 15 minutes) and half-time / full-time lines
